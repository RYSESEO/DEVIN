# CancelKit — First 200 Services Expansion Plan

## Executive Summary

Expand from **46 → 200 services** across **22 categories**, prioritized by:
1. **Subscriber volume** — more users = more API calls from our customers
2. **Cancellation difficulty** — harder to cancel = higher value data
3. **Regulatory attention** — FTC/state AG targets = urgent demand from fintechs
4. **Category diversity** — broader coverage = more buyer personas

### Prioritization Tiers

| Tier | Criteria | Timeline | Count |
|------|----------|----------|-------|
| **P0 — Must Have** | 10M+ subscribers OR FTC enforcement target OR top-3 in category | Sprint 1 (Week 1-2) | ~60 |
| **P1 — High Value** | 1M+ subscribers OR notoriously hard to cancel OR fills key category gap | Sprint 2 (Week 3-4) | ~50 |
| **P2 — Coverage** | Meaningful subscriber base OR completes category breadth | Sprint 3 (Week 5-6) | ~44 |

**Current: 46 services → Target: 200 services (154 new)**

## Next Product Features to Build

### Phase 1 (with Sprint 1) — Core improvements
1. **Automated monitoring bot** — HTTP + DOM change detection for cancel pages; flags stale paths
2. **Search by category endpoint** — `GET /v1/services?category=telecom` (already have this)
3. **Webhook: `path_stale`** — notify API customers when a path changes
4. **Admin dashboard** — internal tool to manage/verify paths quickly

### Phase 2 (with Sprint 2) — Monetization
5. **Stripe billing integration** — self-serve API key upgrades (Free → Starter → Growth)
6. **Tier-based feature gating** — Free: cancel only; Starter: all lifecycle; Growth: signals + billing
7. **Report resolution tracking** — close the loop on broken path reports
8. **Bulk export** — CSV/JSON feed for enterprise customers

### Phase 3 (Sprint 3+) — Intelligence
9. **Retention offer tracking over time** — build historical dataset of offers by service
10. **Automated path discovery** — use headless browser to detect cancel flow changes
11. **Service comparison endpoint** — `GET /v1/compare?domains=netflix.com,hulu.com`
12. **Cancellation success tracking** — API customers report whether paths worked, improving confidence scores
